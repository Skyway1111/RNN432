# Quantization tree: deterministic particles with exact 1-D steps

> K deterministic atoms for the state, each new input integrated exactly in 1-D: error falls like K^(-1/t), not K^(-1/2).
> It is deduction-projection, but the state manifold after t steps is t-dimensional. Sampling's error falls like K^(-1/2). It loses beyond t ≈ 2 unless the relevant state is low-dimensional, and [linearity.md](../../../research/findings/linearity.md) says it isn't.
